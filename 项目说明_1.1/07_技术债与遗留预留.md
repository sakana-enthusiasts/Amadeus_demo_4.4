# 技术债与遗留预留

当前未解决问题按实际实现记录；任务和 Gate 以 06 为准，不把预留或研究倾向当授权。结构清理不等于完成科研功能或修复全部业务技术债。

## 清理与保留判定

- 保留 GP、BoTorch、候选评分、独立官能团等未启用插件，统一预测/优化抽象接口，字段对应/预测模型/实验优化/评分权重注释设置、`__init__.py` 与 `.gitkeep`；它们承担扩展或包/目录保留职责。
- 保留显式 alias、旧类名和用途转发入口；静态未引用、`pass` 或 `abstractmethod` 不能单独作为删除依据。
- 保留测试断言、冻结评估工具及参考资料、现有数据和法律声明；测试源码不因发布忽略规则而从本地删除。无内容、fixture 或契约的 SeeThrough示例测试 分类已删除；模型保存等有生命周期语义的 `.gitkeep` 继续保留。
- 删除已结束的一次性交付脚本 `测试/创建配方物性PR.py`：其目标写死为旧 Demo 2.0 仓库和旧分支，正文仍称 Pareto 待实现，且导入即执行发布操作；它不是测试、模型或扩展接口。
- 唯一源码在当前 Git 根，旧源码/Git 和导入残留在项目外保留；内部说明只有 `项目说明_1.1/`，不保留第二份权威说明。历史 benchmark、根运行记录和骨架审计迁入审计区；用户数据不因清理被覆盖。
- 可重建的 `__pycache__`、pytest cache 和明确临时目录可清理；正式 run、审计、科学 benchmark、冻结快照及模型产物默认保留。当前没有自动删除 retained 数据的清理器。

## 已解决

### TD-01 比例细化混用绝对用量和分数（已修复）

局部比例细化从组装后的规范化质量分数生成守恒正邻域，再走原组装/评价；质量组成签名不再混用绝对投料，已有回归覆盖。

### TD-09 集成回归与可重复 fixture（已修复）

原 8 个误称插件单测的科学断言归并到两份补充数据回归；同一输入各共享一次只读临时 run，UI 共享已生成结果，真正无标签/重跑/按钮场景独立隔离。integration 显式 marker，conftest 不再猜名字。41 条结构与对应身份输入约 31 KB，明确版本控制，不复用个人完整缓存或历史结果。普通测试只依赖 canonical API，旧入口由兼容边界测试承担。

### TD-11 补充数据2干净根输入契约断链（已修复）

标签验证原先读取自身尚未生成的统一记录，且冲突检测隐式依赖以前导入的补充表3。现在自动筛选中间记录 → 本轮结构/描述符合并 → 可选标签验证 → 本轮筛选目录唯一统一记录；冲突检测本轮导入表3。移除模型目录重复保存及 return 后不可达旧算法。干净根与故意污染旧结果/前轮 run 的测试均保持 1619/41/20、final10 10/10。旧算法 CSV 原样移到审计 legacy，新运行不再生成。

### 架构边界封口（已完成）

UI 具体插件执行、管理器穿透、用途元数据依赖算法模块已关闭；上传 parser 单一来源，通用规则预设移到设置工厂，旧入口只委托。毒理查询准备移到现有领域模块，未新增平行服务层。新增生成 CSV 标识约束及架构回归。

## 当前真实技术债

### Target Profile v1 执行边界

已接发现与CLI、现有约束/Pareto，未接UI；执行桥已连接四类组装输入，其他公开 endpoint 尚未连接。支持五类formulation物性/成本、molecule原分子量及11个正式2D计算指标硬约束/报告；其余指标/作用域、分子目标聚合、布尔equals与可靠单位换算尚未支持。RDKit计算属性不是实测，measured_only预检失败。成本derived、原分子量来源类型未细分的行为不变。扩展RDKit报告尚未逐项审查单位/科学语义，不自动升级正式metric。

### TD-02 功能插件私有调用和内部函数依赖

确认批次描述符私有调用已解决：普通描述符与确认批次分别使用 RDKit分子属性计算器的公开 API，保持不同输入/输出 adapter，公式只有一份。比例优化和自动组合现在共同导入 `配方定义构建.py::组装定义`；旧自动组合路径保留同名导出。HSP 三类表格 adapter 共用 HSP计算核心，不合并各自参照/缺失/保存语义。发现约束依赖公共纯组成签名，不能把共享纯函数误认为业务互调。

### TD-03 界面越界与用途绑定

配方构建页面已使用公开 `解析物性配置`，旧 `_配置对象` 仅为函数别名。身份审核与图表重绘已改用核心 facade，UI 不再 import 具体插件或穿透管理器；用途元数据移到设置，上传解析移到核心，物性默认注册表从装配层获取。确认草稿与用途评估限制颅骨用途、用户 HSP 前置绑定 SeeThrough 参照仍保留；这些业务绑定未通用化。

### TD-04 接口完整性和替换注入不足

功能插件通用上下文/返回仍为 Any，类型与具体业务字段边界尚待深化。canonical/alias/重复保护已实现；数据管理抽象接口已补软件数据库写入、目标写保护与正式路径声明，不能继续作为未解决债务。研发生成/筛选/约束/排序/比例优化已通过获取器调用，默认选择已集中到默认装配；用途默认列表和确认描述符直接构造已移除，自定义物性注册表继续保留。通用获取器只声明基础执行 ABI，Profile 预检仍依赖物性汇总公开的注册表指标列表；该专用扩展已在 03 明确。公开聚合及执行桥支持 EvidenceResolver 注入，ProviderRegistry、Repository、raw cache 注入保持兼容。不得描述为全平台所有实现均可无改动替换。

### TD-05 数据与标识边界

本轮补齐生成 CSV 标识的统一读写/存在检查，拒绝路径、盘符、空值和父目录片段；软件数据库表格同样校验。论文原件路径、确认批次/用途存储和非 CSV 导出契约未重写，仍不宣称全面路径沙箱。公开身份接受本地候选编号回退为全局 compound_id，共享证据库存在跨运行碰撞风险；已有 observed structure 隔离不能涵盖空结构场景。

### TD-06 近似与缺失覆盖不足

用途描述符聚合根据单位包含 `%`/“百分”判定可加权，并对有值成分重新归一化；可能混基准、在部分缺失时仍输出近似值。虽然已标记筛选近似，不能当完整真实混合物物性。直接物性入口部分温度/波长一致性依赖来源，校验弱于完整组装；公式区间与误差大多未量化。

### TD-07 多种存储路径与旧报告契约

用户、CLI、SeeThrough 补充数据2/3共用正式 run；新论文运行和当前页面不读前轮结果，报告模式标识已修正。旧固定输出只保留历史浏览兼容。全局确认/用途 CSV 与 run 生命周期仍并存，用途同批次覆盖而非不可变历史；这涉及独立批次/冻结契约，不在本轮迁移。

### TD-08 兼容层与静态未使用线索

工厂旧别名、PubChem/CompTox/论文适配旧类名、旧用途模块和最终结果回退仍保留。旧模块仅导出唯一实现，内部代码使用 canonical 路径；普通用途功能插件的反向编排依赖已移除，历史运行器由核心提供，旧 shim 负责导出。PubChem 参数适配复用原 Provider/缓存/解析，没有另一条网络实现。异常类空 body、SQLite 自动事务钩子和 Parquet close 的 pass 有当前实现理由，不视为未实现功能。

### 明确保留的编排边界

基础插件 `执行(Any) -> Any` ABI 不在本轮全量强类型化。运行管理器的隐式当前 run 和显式 run_id 并存，当前本地单运行模型保留，只有并发/多用户需求明确时再设计 immutable run scope。全局确认/用途批次覆盖涉及冻结与历史语义，继续保留。EvidenceResolver 注入及 Public Evidence Execution Bridge 首版已完成。

SeeThrough 规则插件的专用 `执行数值初筛` / `执行最终自动规则筛选` 是现有论文链契约，不为统一 ABI 重写。配方研发流程不机械拆分；新能力以独立契约使用专用模块/Protocol，流程只编排，不承载新模型实现，也不预建空接口。TD-10 继续等待证据，不猜测历史来源。

## 处理规则

4.4 已关闭首版公开证据到执行候选的断链和 Resolver 注入限制。真实剩余边界：Mordred 尚未在当前环境进行真实 integration；扩展 descriptor 单位/科学语义未逐项审查，继续 report-only；3D 描述符、microstate population、全局模型校准和光谱算法未实现。FPSim2/HSP Advanced/外部预测器/alerts/下游光谱契约按 06 的 Gate D–K 继续，未完成规划不自动归类为 bug。

技术债并非自动开发授权。本轮结构与产物治理范围见 06；本轮按附件重新核验架构封口 Gate A 并通过默认离线测试，已进入 Gate B/C；历史 Gate 1 的 TD-10 证据缺口继续保留；TD-11 以真实干净根科学回归关闭，TD-10 证据缺口仍保留。现有公共证据、物性、组装和发现不能称为全未实现，完整论文链亦不能被已有运行文件掩盖。



### TD-10 数字目录历史来源证据缺口

当前现场无 13 位数字目录，静态限定搜索和受控测试未复现生成。此前目录内容/时间/生成命令均缺失，不能断言为 pytest/Codex 或其他外部工具，不删除无法证明的用户结果。需要下次出现时记录现场和逐命令前后目录差异，再修实际生成源。

确定性分子属性已区分 computed/predicted；11 项正式指标及独立计算报告为 computed，any 可接受，其余现有实测/预测要求不得接受 computed。真正 QSAR/pKa/logD/ADMET 模型尚未进入，没有第二套分子证据系统。
