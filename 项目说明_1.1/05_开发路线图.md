## 严格优先顺序

### 已完成的架构硬化：Composition / Dependency Boundary Hardening

- [x] 工作流默认具体实现集中到唯一默认装配点，复用功能获取器，保留 canonical/alias 与专用接口。
- [x] 研发与用途移除具体功能插件构造，保留自定义物性注册表，增加装配/注入/有限 AST 回归。
- 本阶段完成后仍须通过既有 Gate 1，再进入 Public Evidence Execution Bridge；不改变以下科研功能优先顺序。

4.4 按本轮附件 Gate A 核验封口后，完成 Gate B 公开证据执行桥与 Gate C 标准化/描述符。后续实施 Gate 和真实未完成项见 06；历史 TD-10 保留，不能用默认测试宣称历史来源已查明。

### P0：Core Runtime / Storage Hardening

- [x] canonical ID、显式 alias、duplicate protection、原子替换和诊断列表。
- [x] 用户/CLI/SeeThrough 正式 run 位置统一；run_id 与激活路径检查。
- [x] computed/predicted 分开，确定性 RDKit 指标标为 computed。
- [x] 数据管理真实写入/路径能力契约补齐；测试临时根与默认离线防护。
- [ ] Gate 1 完整通过：补充数据2干净根断链已修复，科学回归恢复；历史数字目录来源仍待可复现证据。默认测试通过不替代完整集成科学回归。

### 已完成的架构前置收尾：Architecture Boundary Closure

- [x] UI 执行统一走核心 facade；上传 parser、用途元数据、规则预设独立归位。
- [x] 默认物性注册表由装配层对外提供；毒理查询准备下沉领域流程；CSV 标识读写统一安全校验。
- [x] 兼容入口保留，增加依赖边界、输入安全及页面按钮回归；不作为新的科研阶段。

### P1：Public Evidence Execution Bridge

- [x] 首版适配 molecular_weight/density/refractive_index/viscosity 的 ResolvedProperty 到执行候选视图；只补缺失字段，保留原记录/provenance/冲突和条件，off 默认、cache_only 不调用 Provider、fetch_missing 显式且最多 100 个候选。

- [ ] 其他 endpoint 的执行绑定和 UI。

### P2：HSP Advanced

### P4：Structural toxicology / ADME / QSPR

### P5：后端成熟后的 Query Builder / UI

- [ ] advanced Query Builder、高级 workflow UI。

模型误差校准、全局身份、解除用途绑定、其他 scope/metric/工具及 molecule 目标聚合仍需独立定义任务。Agent、BoTorch 实验闭环、口服递送和研究计划专用功能不属于当前主线或授权。

未来固定在普通物质筛选和基础配方生成/评价之后。独立色素池、discovery/rescue、光谱契约及下游 hook 是 Gate K 的未完成项，本版未创建接口或算法。不得进入普通初筛、默认配方或改变现有 RI 公式。
