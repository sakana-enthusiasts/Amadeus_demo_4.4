## 实际完成 Gate

- Gate A：确认 4.3 架构封口，默认离线测试通过；未混入上一轮重构。TD-10 历史目录来源证据仍缺失，未伪造关闭；本轮按附件 Gate A 判断进入新阶段。
- Gate B：PublicEvidenceExecutionBridge、EvidenceBridgeConfig，四类物性进入派生执行候选和现有配方组装；默认 off、cache_only 不调用 Provider、fetch_missing 最多 100 个候选且联网前检查。显式映射发现物质编号与公共 compound_id，要求 observed_structure/chemical_form，不猜身份。原输入/证据不改，原用户值优先保留、冲突独立记录。测量/预测/本地 computed 分开。聚合器与执行桥支持 Resolver 注入；联网复用公开聚合器。
- Gate C：工具无关分子标准化契约与 RDKit 实现；只对选定计算视图操作，记录 sanitize/canonical/fragment/cleanup/uncharger/parent/tautomer 步骤、片段、形式电荷、版本。扩展描述符契约位于现有分子属性模块，复用 RDKit 计算器并适配 Mordred-community 2D API。显式请求才运行，不生成 3D、不注册海量指标。

发现顺序仍为显式原池 → 可选 Structure Query → Profile 预检/数值自检 → 可选标准化 → 原正式分子属性 → 可选 Descriptor Engine → 可选公开证据桥 → 独立候选筛选 → 原组合/组装/物性/约束/Pareto → 比例细化再评价 → Benchmark 最后加载。新功能默认关闭时返回保持兼容。

- RDKit：当前环境已有，真实标准化及描述符测试通过；Amadeus 只提供契约/调用适配，不复制算法。
- Mordred-community：官方 PyPI 核对版本 2.0.7、BSD-3-Clause；写入可选 requirements-chemistry.txt，未安装到主环境。完成 API adapter、缺依赖检测及 mock 计算验证，未声称真实后端已验收。
- 原 11 项 CORE_METRICS 与现有绑定语义保留。扩展描述符全部 report-only。显式 Bridge 开启时 molecular_weight 可接受实际采用的 measured/predicted；用户原分子量仍 unspecified，不因旁边有公开证据就变为实测。密度/RI/黏度只补已审查单位/温度/相态/波长的组装输入，未新增分子级 Profile metric。
