# 项目定位与边界

当前软件版本：Amadeus_demo_4.4；说明修订：项目说明_1.1。说明修订不改变软件版本，也不改变 Target Profile JSON 的 1.0 格式。本目录沿用 00–07 和 `模块/` 的原有结构，是项目架构、接口、路线图和任务范围的唯一内部权威说明。说明与实现冲突时核对真实接口并纠正说明，不根据旧文字反向生成需求。

## 长期定位

Amadeus 是模块化、可扩展、可替换的科研候选筛选、证据整合和配方研发平台。当前主要应用场景为颅骨透明化，保留 SeeThrough 参考流程；底层公共能力不得绑定单一用途或研究计划。

公共层提供插件编排契约、数据管理、规则与属性契约、Target Profile、结构查询、单分子计算、公开证据和独立配方物性模型。用途层使用公共结果表达当前场景的目标、成分/配方评价、终点与约束。现有确认草稿与用户 HSP 前置计算仍有用途绑定，限制见 [07](07_技术债与遗留预留.md)。

## 目录与需求边界

本版根目录以本版 AGENTS、README、生产入口和 Git 仓库边界确定，不能仅凭外层文件夹名判断。当前 Git 根只保留一套现行 4.4 源码；旧源码、旧 Git 状态和导入压缩包放项目外，不再保留完整项目嵌套、源码 snapshot 或 `.tmp_*source*`。不创建 `versions/`、`src/`、`app/` 或新项目外壳。

README 面向使用者，不是需求来源。许可声明、运行结果、研究计划、PPT、论文、实验方案、冻结评估材料和审计历史不得自动转成软件需求。未来与预留接口不构成实施授权。

当前不实现 Agent，不建空框架；底层不得依赖它。实验闭环、口服递送或特定研究计划不是当前平台主线。能力优先顺序以 [05](05_开发路线图.md) 为准，当前任务与 Gate 以 [06](06_当前版本任务.md) 为准。

现有扩展占位与兼容入口按 [07](07_技术债与遗留预留.md) 保留；不新增空框架不等于删除已保留的抽象接口、未启用插件、设置占位或 `.gitkeep`。
