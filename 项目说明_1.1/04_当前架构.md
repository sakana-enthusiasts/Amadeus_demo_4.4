## 入口与装配

`streamlit run 启动程序.py` 进入现有页面与核心公开流程；主界面版本标识为 Demo 4.4，用途绑定仍存在。`运行配方研发.py` 提供验证/发现 CLI，可从 JSON 读取候选、配置、约束与 Target Profile。发现候选池为空，须显式提供独立输入或开启演示库。结构查询与分子属性通过 Python 发现接口显式接入，CLI 尚无对应查询/结构映射参数，不能把 Python 能力都表述成 CLI/UI 已可配置。

控制器兼容工厂创建运行数据管理器，委托 `默认装配.py` 创建功能插件管理器。默认装配包含原正式插件及自动配方组合、配方候选排序、配方比例局部优化、独立候选分子筛选、发现配方约束评价，不锁定注册总数。注册不再依赖调用方手写 canonical 字符串；公开证据聚合的 PubChem查询、普通表格导入的补充数据2表格导入为显式 alias。注册/替换/查找只管理功能实例，业务编排仍由核心流程负责；专用计算器、检索器、Provider、Repository 与物性策略不迁入通用插件 ABI。

论文导入、标签验证、CompTox 状态及用途功能文件按真实职责命名，默认装配使用 canonical 路径，旧模块仅导出兼容类。用途插件不导入核心编排，旧运行器移至核心；配方定义构建由粗搜和细化共用，公式未变。批次存取、流程编排和用途规则仍各自分工。

页面通过控制器公开入口执行人工身份确认和图表重绘，不再依赖具体插件或穿透管理器。CSV/XLSX 预览与导入使用核心候选表输入模块；用途元数据由设置模块统一提供。配方构建/研发页面通过默认装配获得独立物性模型注册表。规则预设集中在设置工厂，通用引擎保留数据结构与执行；毒理候选准备属于毒理分析流程，控制器只转发。CSV 数据标识在读写时统一拒绝路径逃逸。

## 用户、论文与用途

用户文件/映射/配置 → 创建 run_id → 通用导入 → 身份/结构 → RDKit 描述符 → HSP 初筛 → 原规则引擎 → 报告。用户和 CLI 运行产物均进入 `数据/运行记录/run_.../`。SeeThrough 补充表入口每次创建独立 run，活动 run 不回退固定历史结果；软件数据库、确认和用途 CSV 仍为全局存储。

论文补充表仅作为参考复现；最终标签在自动选择后用于对照。两条链均从声明的论文/离线输入生成本轮结果。补充数据2的标签验证读取自动记录并追加结构/描述符，唯一统一记录保存在本轮筛选目录；冲突检测本轮导入补充表3。干净根保持 1619/41/20 与 final10 的 10/10。

候选 → 工作草稿 → 明确确认 → 冻结批次 → 描述符/当前用途评估。核心评估编排完整组装、用途目标、HSP、五类物性、实验终点、特征和用途约束。草稿仍限制颅骨用途，同批次用途结果覆盖；终点和特征入口不代表训练或优化已实现。

## 发现执行与子系统

显式原候选池 → 可选 Structure Query → Profile 编译/预检与数值自检 → 可选标准化计算视图 → 按需 Molecular Property → 可选扩展 Descriptor Engine → 可选公开证据执行桥 → molecule 约束/报告与本地筛选 → 有限质量分数组合 → 原输入组装 → 配方物性 → 原约束 → 唯一 Pareto → 比例细化/再评价 → Benchmark 最后加载。

Structure Query 独立检索本地集合，支持 exact、SMARTS substructure、Morgan/Tanimoto similarity；Molecular Property 计算单分子 11 项正式 2D 指标，独立保存结果与工具出处，value_kind 为 computed，不覆盖用户属性或组装分子量。扩展 catalog 仅供显式报告。

Target Profile 提供独立规格/JSON、纯绑定和 ExecutionPlan；已接发现/CLI、现有约束/Pareto。支持五类 formulation 物性/成本、molecule 原分子量及 11 项计算指标硬约束/报告。computed 只满足 any，不伪装 predicted。molecule objective、其他 scope、数值 equals 与可靠单位换算仍不支持；UI 配置和四类物性以外的公开证据执行连接尚未实现。

## 公开证据与物性

分子标准化使用 RDKit 真正实现，默认不启用，不改 Structure Query v1。Descriptor Engine 复用 RDKit，并以 Python API 适配可选 Mordred-community 2.0.7，仅显式请求的 2D 描述符；扩展结果独立报告，不升级为正式 metric。Mordred 当前环境未安装，仅 adapter/mock 验证。FPSim2、HSPiPy、OPERA、Dimorphite-DL、ADMET-AI、结构警报和下游光谱/色素契约尚未实现，也未安装或复制其模型/源码；本版完成到 Gate C。

独立公开查询 → 聚合插件 → ProviderRegistry/PublicDataProvider → 来源 client/raw cache/parser → EvidenceRepository → EvidenceRequest/EvidenceResolver → ResolvedProperty 与日志。核心证据层不导入具体来源；PubChem、CompTox、NIST、ThermoML 独立实现。Repository 支持 DuckDB/SQLite/Parquet；raw cache 独立，可注入来源/存储/缓存，Resolver 可注入。公开证据执行桥默认 off；cache_only 只读 Repository，fetch_missing 通过同一聚合器显式获取缺失证据且最多 100 个候选。四类物性仅补入派生候选的缺失字段，原输入/证据与冲突完整保留。

配方物性汇总通过模型注册表选择独立 `预测(配方, 上游)` 策略，按声明依赖调度并检查环。已注册 Lorentz–Lorenz，Grunberg–Nissan/Cheng 甘油–水/理想对数黏度，Stokes–Einstein，理想或系数修正渗透压及水活度。实测优先、缺失保留；组织扩散、滞留、washout 和毒理风险保持未知。

毒理保持现有三态会话、条件匹配与 A/B/C/D 语义；旧公开毒理入口仅 PubChem GHS，危险提示不参与实验条件匹配。CompTox 远程领域证据不等于已接旧毒理匹配或本地模型。
