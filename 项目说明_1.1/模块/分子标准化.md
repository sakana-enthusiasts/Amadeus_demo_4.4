# 分子标准化

`核心系统/分子标准化/` 提供 StandardizationRequest、StandardizedMolecule、StandardizationStep 和 MoleculeStandardizer Protocol；不导入 RDKit、Provider 或 UI。默认装配通过 `创建默认分子标准化器()` 返回 `RDKitMoleculeStandardizer`。

输入保存 compound_id、observed_structure、observed_format（首版 smiles），calculation_view 为 observed/canonical/parent/canonical_tautomer。默认 canonical 只解析/sanitize、canonical SMILES 与报告原始 fragments，不默认 parent 化或电荷中和。

- normalize_charge=True：显式调用 RDKit Cleanup 与 Uncharger，并分别记录前后结构；不是指定 pH 的物种预测。
- extract_parent=True 或选择 parent：FragmentParent(skipStandardize=True)，保留盐/片段原件，不归并身份。
- canonicalize_tautomer=True 或选择 canonical_tautomer：从 canonical 视图调用 TautomerEnumerator.Canonicalize，不隐式去盐，不预测丰度。

每项结果保留 observed、canonical、parent、canonical_tautomer、原 fragments、选定计算视图的 formal_charge、步骤/工具/版本/警告和失败原因。无效输入为 invalid_structure，算法失败为 calculation_failed；失败 calculation_structure=None，不回退原结构并伪装成功。

发现入口增加 `标准化配置=None, 分子标准化器=None`。配置 None 时不调用；显式空字典启用默认 canonical。复用原结构字段映射，先执行原 Structure Query，再标准化命中候选。原结构字段和身份不改，只添加独立标准化计算视图给后续正式分子属性与 Descriptor Engine 使用。报告保留完整标准化结果；Profile 和原 Structure Query 的默认语义不变。

```python
from 核心系统.分子标准化 import StandardizationRequest
from 核心系统.默认装配 import 创建默认分子标准化器

result = 创建默认分子标准化器().standardize([
    StandardizationRequest("salt_a", "CC(=O)[O-].[Na+]", calculation_view="parent")
])[0]
assert result.observed_structure == "CC(=O)[O-].[Na+]"
```

算法复用 [RDKit MolStandardize API](https://www.rdkit.org/docs/source/rdkit.Chem.MolStandardize.rdMolStandardize.html)。Amadeus 只实现选项、步骤记录与派生视图适配；没有自研去盐、互变异构体或 pKa 模型。
