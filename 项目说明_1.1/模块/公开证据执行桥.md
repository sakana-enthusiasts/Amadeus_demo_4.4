# 公开证据执行桥

`核心系统/公开证据/执行桥.py` 是公开证据到执行候选的唯一投影层，不是第二套证据库。`PublicEvidenceExecutionBridge(repository, resolver=None, fetcher=None)` 通过 `query`/`resolve` 使用现有契约；`apply(candidates, requests, config)` 返回派生候选列表和报告。Repository 和 Resolver 资源归调用方所有。

`EvidenceBridgeConfig(mode="off", max_candidates=20)` 接受 off/cache_only/fetch_missing。off 直接返回原候选和空报告，不访问依赖。cache_only 只查询 Repository，不创建或调用 Provider。fetch_missing 只查询解析结果为 missing 的候选；先检查完整待联网候选数，不超过配置值及绝对上限 100，超限报错且不发请求，不静默截断。没有 fetcher 时明确报告 capability_unavailable；冲突不触发自动联网覆盖。

requests 以发现 `物质编号` 为键，值是 `EvidenceRequest` 序列。公共 `compound_id` 不隐式取本地编号，必须明确提供 observed_structure 和 chemical_form；拒绝 unspecified 形式和 allow_unknown_conditions。同一候选各请求身份必须一致、属性不能重复；Structure Query 已排除的候选不执行查询。

| property_id | 执行字段 | 接受的 Resolver 规范单位 | 额外要求 |
| --- | --- | --- | --- |
| molecular_weight | 分子量_g_mol | g/mol | 有限正值 |
| density | 密度_g_mL | kg/m3，投影乘 0.001 | 明确温度 K，投影为密度温度_C |
| refractive_index | 纯物质RI | 空字符串（无量纲） | 明确温度、phase=liquid、wavelength={value:正数, unit:nm} |
| viscosity | 纯物质黏度_mPa_s | Pa s，投影乘 1000 | 明确温度、phase=liquid |

只投影 measured/predicted 的 resolved 单值，summary/derived 只报告；限定值、未知单位、非有限/非正值、溶液条件及与已有用户条件冲突的值不执行。原始用户字段只要已填写就保留，既不覆盖也不修正；差异写入 conflict。默认 Resolver 保留其既有排序和 10% 冲突容差，不平均。原证据不变，规范化副本只用于执行视图。

每项报告保留 compound_id/property_id/value/unit/conditions/chemical_form/evidence_type/source/method/model、完整原证据 provenance、原 evidence_ids、resolver_status/conflict/reason、原请求、applied 与执行字段/值/单位。派生候选的 `公开证据` 命名空间随配方组装保留；原物质库快照仍是用户原输入。本地 computed 仍使用独立 `分子计算属性`。

通过 `运行发现模式(..., 公开证据配置=..., 公开证据执行桥=..., 公开证据请求=...)` 接入，位于分子计算后、独立候选筛选前。关闭时不改变原输出。molecular_weight 在显式启用 Bridge 的预检中允许 measured/predicted，评价时只采用实际补入该执行字段的证据类型；用户已填值仍 unspecified。其他三项进入既有组装，不新增 Profile metric 或改变配方公式。

`核心系统/默认装配.py::创建公开证据执行桥(证据存储, 证据选择器=None, 查询上下文=None)` 只装配。提供查询上下文后，fetch_missing 通过 `插件/公开数据/执行桥查询适配.py::ExecutionEvidenceFetcher` 调用现有公开聚合器；调用方可提供数据源注册表/原始缓存/目录等现有上下文。装配本身不读数据、不联网。聚合器新增 `证据选择器` 注入键，旧调用兼容。

```python
from 核心系统.公开证据.执行桥 import EvidenceBridgeConfig
from 核心系统.公开证据.数据结构 import EvidenceRequest
from 核心系统.默认装配 import 创建公开证据执行桥

# repository 为调用方管理的 EvidenceRepository，避免默认打开真实用户数据库。
bridge = 创建公开证据执行桥(repository)
view, report = bridge.apply(
    [{"物质编号": "water"}],
    {"water": [EvidenceRequest("pubchem:962", "molecular_weight",
        chemical_form="neutral", observed_structure="O")]},
    EvidenceBridgeConfig("cache_only"),
)
```
