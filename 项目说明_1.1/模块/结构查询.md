# Structure Query v1

公共契约：核心系统/结构查询/数据结构.py、接口.py、__init__.py，不依赖RDKit/UI/Provider。RDKit实现独立于原身份结构处理插件，支持search(query, candidates)及功能插件执行入口；无联网和用途依赖。

StructureCandidate明确compound_id/原始structure/structure_format（v1仅smiles）。StructureQuery明确mode/query/query_format/use_chirality；SimilarityConfig仅用于similarity。StructureHit保存status、canonical、适用score/match_count/atom_indices及reason/warning。StructureSearchResult保存query/engine/version/canonical_query/hits/invalid_candidates/excluded_candidates；to_dict返回独立快照及result_count/invalid_count/settings。身份重复报错，候选解析失败单独invalid_structure，无效查询抛StructureQueryError。

Exact：相同RDKit解析规则下canonical isomeric SMILES相等。默认use_chirality=True；False仅去立体信息，保留同位素，不合并盐、tautomer、parent或protonation。原始输入/canonical/stereo设置/RDKit版本保留，不声称完整同一物质语义。

Substructure：仅显式SMARTS，使用GetSubstructMatches，unique匹配数及atom indices；max_matches默认10000，可配置，达到上限警告实际可能更多。use_chirality显式记录，无效SMARTS失败，不伪装零命中。

Similarity：Morgan fingerprint generator，默认radius=2/fp_size=2048，includeChirality由use_chirality指定，BulkTanimotoSimilarity。先threshold（含边界）再score降序/compound_id升序取top_n。threshold有限且在[0,1]，top_n正整数，可分别或同时设置。算法参数和RDKit版本完整记录。query分子/指纹只计算一次，输入不修改。

```python
from 核心系统.结构查询 import StructureCandidate, StructureQuery, SimilarityConfig
from 插件.化学计算.RDKit结构检索插件 import RDKit结构检索插件
query = StructureQuery("similarity", "CCO", "smiles",
    similarity=SimilarityConfig(threshold=0.3, top_n=10))
result = RDKit结构检索插件().search(query,
    [StructureCandidate("local_a", "OCC", "smiles")])
```

发现入口：运行发现模式(..., 结构查询=query, 结构字段映射={"id_field": "物质编号", "structure_field": "SMILES", "structure_format": "smiles"}, 结构检索器=None)。字段映射必须显式提供；可注入StructureSearch实现，未注入时由 `核心系统/默认装配.py::创建默认结构检索器` 选择 RDKit，业务流程不导入具体检索类；仍使用专用 StructureSearch，不进入通用插件注册。原池→结构查询→现有分子筛选/Profile→组合→预测/约束/Pareto→比例优化→Benchmark最后加载。无查询保持legacy，不修改Profile或建立第二套约束/排序。

仅用户明确本地池，独立检索无限100种限制，现有自动组合筛后池仍限100种。无 persistent fingerprint index/cache 或 UI Query Builder，不支持 reaction/Markush/3D/pharmacophore；后续路线集中见 05。验证覆盖科学语义、阈值/排序、输入保护、无效结构、元数据、工具无关契约导入、发现顺序及无联网。

Molecular Property复用StructureCandidate/adapt_candidates和显式id_field/structure_field/structure_format，不新建猜结构机制。有查询只计算命中候选；无查询也允许提供同一映射用于单分子属性。搜索决定集合，分子属性对集合计算描述符；属性结果独立保存在分子属性结果/分子计算属性，不塞进StructureSearchResult。之后继续唯一候选筛选、组合和约束/Pareto，Benchmark仍最后加载。
