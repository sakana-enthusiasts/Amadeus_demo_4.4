# Molecular Property / Descriptor Execution v1

本模块提供单分子稳定2D计算公共能力，不重建筛选框架。Structure Query决定候选集合；Molecular Property计算单分子属性；Target Profile定义筛选/报告需求；Formulation Property计算混合配方性质。

## 正式指标

以下11项均允许molecule hard_constraint/report_only，不允许objective。来源为`RDKit 2D descriptor calculation`，工具RDKit，engine_version取实际运行版本。无量纲unit为空串，Profile省略unit；其他显式单位须完全相同，不隐式换算。

| metric_id | 数据类型 | unit | method | 原始descriptor_name |
| --- | --- | --- | --- | --- |
| logp | float | 无量纲 | Crippen.MolLogP | MolLogP |
| tpsa | float | Å² | rdMolDescriptors.CalcTPSA | TPSA |
| h_bond_donors | int | count | Lipinski.NumHDonors | NumHDonors |
| h_bond_acceptors | int | count | Lipinski.NumHAcceptors | NumHAcceptors |
| rotatable_bonds | int | count | Lipinski.NumRotatableBonds | NumRotatableBonds |
| aromatic_rings | int | count | Lipinski.NumAromaticRings | NumAromaticRings |
| ring_count | int | count | Lipinski.RingCount | RingCount |
| heavy_atom_count | int | count | Lipinski.HeavyAtomCount | HeavyAtomCount |
| hetero_atom_count | int | count | Lipinski.NumHeteroatoms | NumHeteroatoms |
| fraction_csp3 | float | 无量纲 | Lipinski.FractionCSP3 | FractionCSP3 |
| formal_charge | int | e | Chem.GetFormalCharge | FormalCharge |

Rotatable bonds沿用RDKit默认定义（与旧插件相同），ring_count沿用RDKit环感知，不等于所有可能环的枚举；fraction_csp3为碳原子中sp3比例。TPSA使用默认2D函数参数。SMILES保留立体、同位素、盐/电荷形式，不预测pH物种、不自动去盐或合并tautomer。方法以[RDKit官方Lipinski API](https://www.rdkit.org/docs/source/rdkit.Chem.Lipinski.html)及[描述符文档](https://www.rdkit.org/docs/source/rdkit.Chem.Descriptors.html)为准。

## 公共契约和实现

核心系统/分子属性/的数据结构、Protocol和公共入口不import RDKit。MolecularPropertyResult保留metric_id/value/unit/value_kind/status/method/engine/engine_version/source/canonical_structure/structure_format/reason/warning/descriptor_name。available必须有有限数值及canonical；invalid_structure/unsupported/calculation_failed必须value=None且reason明确，不泄漏NaN、不填0。CandidateMolecularProperties保留稳定compound_id、原始结构、properties及独立extended_report，to_dict可严格JSON导出。

RDKit分子属性计算器提供calculate(candidates, requested_metrics, extended_descriptors=None)、metric_catalog()、descriptor_catalog()；输入复用现有StructureCandidate。同批相同原始结构只解析一次，所有所需指标共享Mol；失败逐descriptor隔离。没有默认并行、持久缓存或数据库读写。

```python
from 核心系统.结构查询 import StructureCandidate
from 插件.化学计算.RDKit分子属性计算器 import RDKit分子属性计算器

engine = RDKit分子属性计算器()
batch = engine.calculate([StructureCandidate("local_a", "CCO", "smiles")],
                         ["logp", "tpsa", "h_bond_donors"])
snapshot = batch[0].to_dict()
# 仅显式请求时计算扩展报告：
report = engine.calculate([StructureCandidate("local_a", "CCO", "smiles")], [],
                          extended_descriptors=["MolWt", "BertzCT"])
```

`rdkit_molecular_weight`只可作独立计算报告，method=Descriptors.MolWt，unit=g/mol，不注册新的Profile分子量绑定，不覆盖物质记录.分子量_g_mol或改质量/摩尔换算。

## Target Profile和发现入口

指标binding.source=分子计算属性，field=稳定metric_id，值类别为computed（确定性计算）。any接受computed；measured_only/measured_or_predicted/predicted_allowed、单位不一致、molecule objective预检明确失败；多成分molecule objective没有定义聚合语义，不能自行平均、最大、质量加权或取主体值。

运行发现模式增加分子属性计算器和扩展描述符报告参数；复用显式结构字段映射{id_field:物质编号, structure_field:调用方指定字段, structure_format:smiles}。有查询先命中再计算；无查询也必须显式映射，不猜字段。执行计划只请求启用核心指标；需要计算且未注入时由 `核心系统/默认装配.py::创建默认分子属性计算器` 选择 RDKit，专用 MolecularPropertyCalculator 不进入通用插件注册。不请求则不创建该执行实例；扩展报告必须指定原始名称列表。

单分子结果放候选分子计算属性独立命名空间，运行分子属性结果保留完整快照；用户/公开同名数值和原分子量不覆盖。规格评价携带value/unit/property_status/source/method/engine/version/canonical和失败原因。missing_policy=keep_unknown保留未知，exclude按现有约束排除，report_only不改变资格。之后沿用候选筛选→组合→配方性质/约束→唯一Pareto/比例优化→Benchmark最后加载。

用户候选规则插件可接显式分子属性结果及既有规则注册表，小型公开分子属性记录adapter沿用run_id/候选编号/属性编号关联。现有属性注册表注册相同11项；失败值None，完整计算出处放条件。不新建规则引擎、不修改UI、不默认计算全部属性。

## Extended report与旧输出

descriptor_catalog查询当前RDKit Descriptors.descList，保留原始名称、版本、未知单位、报告边界。calculate仅计算用户明确请求的名称；结果保留状态、原始名称和版本，未知名称unsupported、单项失败calculation_failed。扩展报告unit=None，warning指出未完成单位/语义契约审查，所有条目target_profile_metric=False；即使原始名称与核心函数相同，也不能自动按扩展名称执行Profile。所有扩展项尚未逐项完成科学审查，也不代表Mordred/PaDEL已接入。

普通描述符与确认批次调用同一公开legacy_descriptors/functional_group_labels API，公式/SMARTS不复制。普通插件维持补充数据2/3、用户入口的输入/输出标识、9个旧基本描述符和18个Fig1c相关字段，数值仍round到6位；结构无效仍输出9条失败记录并保留旧原因。确认批次有效结构输出相同描述符，无效仍单条结构状态。通过公开 API 调用，不依赖功能插件私有方法。

## 当前边界

核心指标与旧输出回归使用离线内存/tmp_path，覆盖契约、简单结构性质、失败隔离、解析复用、角色/单位/值类别、输入保护、按需计算和 Benchmark 最后读取。完整 Gate 结果集中在 06，不把模块说明作为开发记录。

未实现 pKa、logD、solubility prediction、microspecies、tautomer prediction、HSP Sphere、ADMET、结构毒理预测、3D/conformer descriptors、molecule objective 聚合或 Agent。扩展指标正式化和其他工具接入须另定义任务。分子计算结果独立于 PropertyEvidence，不覆盖原始用户数据。


## 4.4 扩展 Descriptor Engine

`描述符契约.py` 提供 DescriptorRequest、DescriptorDefinition、DescriptorValue、CandidateDescriptorSet、DescriptorCalculator。DescriptorRequest 必须给出 descriptor_ids（原始工具名称，如 MolWt/MW），engine 为 RDKit 或 Mordred-community，dimension 首版仅 2D；拒绝重复名称/3D，空请求不执行 Mordred import。结果保留 descriptor_id/value/status/unit/engine/version/method/dimension/canonical_structure/reason/warning，value_kind 固定 computed。失败值 None，不填 NaN 或零；未知单位 None。

`插件/化学计算/扩展描述符后端.py` 的 RDKitDescriptorCalculator 委托现有 RDKit分子属性计算器，不复制公式。MordredDescriptorCalculator 延迟加载已安装的 mordredcommunity，通过 Calculator(descriptors, ignore_3D=True) 取公开目录，再只计算显式名称子集；不生成构象。未安装返回 capability_unavailable，逐项 Missing/Error/非有限值返回 calculation_failed，未支持名称 unsupported。catalog 需要对应后端可用，不能把缺依赖伪装空目录。

发现参数 `描述符请求=None, 描述符计算器=None` 默认不执行；启用时由默认装配创建后端，也可注入专用计算器。结果为 `扩展描述符结果`，不参与硬约束/Pareto。若显式启用标准化，计算的是所选派生视图；原结构和原物质库快照不改。原 `扩展描述符报告` 参数仍兼容。

可选安装声明 `requirements-chemistry.txt` 只含真实适配的 mordredcommunity==2.0.7；当前主环境未安装，完成 mock/缺依赖验证，不能声称真实全量 Mordred descriptor 已验收。版本与接口依据：[PyPI](https://pypi.org/project/mordredcommunity/)、[维护项目](https://github.com/JacksonBurns/mordred-community)。所有扩展 descriptor 仍 report-only；原 11 项 CORE_METRICS 不变。
