# SeeThrough 离线输入

两个 CSV 仅保存补充数据2当前结构分析所需的 41 条 CAS 查询输入，提取自本地已取得的 PubChem 查询缓存。身份输入按结构表 CAS 精确筛选；不包含其他用户候选、筛选结果、计算描述符、Hansen 距离或期待输出。保留源、查询时间、结构和原查询失败/待确认状态，测试不联网补全。

论文原表仍读取 `数据/论文原始数据/SeeThrough补充数据2_1619个水相候选.xlsx` 和 `SeeThrough补充数据3_最终候选与混合折射率.xlsx`；final10 标签与补充数据3结构映射仍使用 `数据/软件数据库/` 下两份已维护的参考表。最终标签只在自动选择完成后验证。

session fixture 将明确输入复制到 pytest 系统临时根，运行真实插件生成独立 run，随后锁定为只读。每张表的多个断言共用该次执行，读取时重新加载 DataFrame；无标签、重复运行和污染场景使用各自临时根。上述版本控制输入缺失视为测试配置错误，禁止从用户缓存或历史输出回退。
